# セッションを締める

セッションで作業した人（人でもエージェントでも）が、締めるよう頼まれてから、持ち越すものを残し、作業領域を片付け
られる状態にして、締めのまとめを答えるまでの手順。目的の手順で、段の中で共通の手順を使う（[目的の手順と共通の
手順](../architecture/documentation.md#procedures)）。決まりは[課題の扱い方](../reference/issues.md "在りか")にある。

締めのまとめを答えたら終わる。そのあとの依頼（持ち越した Issue に取りかかる、開いている PR の指摘に答えるなど）は、
新しい依頼として振り分けから入る。締めたあとも同じセッションに依頼してよい。

1. **始めに読む**：次を全体まで読む。この段は省かない。このセッションですでに全体まで読んだ文書は、読み直さなくてよい。
   - [課題の扱い方](../reference/issues.md)：持ち越すものの置き場所と、Issue とロードマップの決まり。
2. **洗い出す**：このセッションでしたことを見返し、[持ち越すもの](../reference/issues.md#carry-over)を種類ごとに挙げる。
   覚えていることだけで挙げず、依頼のスレッドや会話、このセッションで作ったか更新した PR の本文（確かめていないこと）と
   レビュー（打ち切った提案、範囲の外とした提案）、作業領域（`git status`、`git stash list`、push していないコミット）を
   読み直す。
3. **残す**：挙げたものを、持ち越すものの置き場所に残す。すでにある Issue や PR に当たるものはそこに書き足し、同じ
   ものを二つ作らない。新しい Issue は、ラベルを[課題の扱い方](../reference/issues.md)に沿って付け、読む人がその Issue と
   リポジトリから読み取れることだけで続けられるように書く。文書やコードを直すべきものは、この手順では直さず Issue に
   する（その場で直すなら、[変更を届ける](deliver-change.md "在りか")に入り直す）。自分の書ける範囲の外に置くものは、
   置き場所とともに締めのまとめに書いて、人に渡す。
4. **課題の今の姿を合わせる**：このセッションが扱った Issue（依頼の Issue、PR が閉じるか触れる Issue、分けて作った
   Issue）ごとに、終えたなら閉じ（PR のマージで閉じるものは除く）、範囲を分けたなどで本文の今の姿が古くなったなら書き
   直す。そのうえで、閉じたか起きた Issue があれば（PR のマージで閉じたものを含む）、ロードマップの今の焦点が古く
   なっていないかを確かめ、古ければ本文を書き直す。
5. **片付けられる状態にする**：片付けを止める条件と、セッションが push したブランチの見分け方は、動き方ごとにハーネスの
   契約にある（control-plane 経由なら、platform の[ハーネスの契約](../../../../docs/reference/harness.md#lifetime "在りか")の
   コンテナの寿命と作業領域とブランチ）。
   - 作業領域にしかないもの（その条件のうち作業領域にあるもの）は、PR に載せるなら変更を届けるに入り直して載せる
     （終えた PR に、レビューしていないコミットを足さない）。載せないなら、残す価値のある中身を Issue に書いてから捨て、
     捨てたものを締めのまとめに書く。
   - このセッションの名前のブランチ（control-plane 経由なら `$ACP_SESSION_BRANCH` と `$ACP_SESSION_BRANCH-<内容>`）と
     push したブランチ、その PR を挙げる。このセッションの名前のリモートのブランチのうち、head ブランチか base ブランチと
     する開いている PR のないものは、同じように中身を残してから消す。ほかの名前のブランチは消さない。
   - 開いている PR は、人がマージするか閉じるまで残る。
6. **締めのまとめを答える**：最後の回答に、次をこの順で書く。
   - 残したもの：Issue と PR へのリンクと、それぞれ何を残したか。
   - 人がすること：マージしてほしい PR、決めてほしいこと、書ける範囲の外に置いてほしいもの。
   - 片付けを止めているもの：開いている PR など、残る理由。なければ、片付けられる状態になったこと。
   - 続け方：別のセッションで続けるときは、このスレッド（か会話）の在りかと、持ち越した Issue を渡せばよいこと。
