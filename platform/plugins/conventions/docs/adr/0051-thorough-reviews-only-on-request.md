# 0051. 念入りの回し方は、依頼者が念入りに頼んだ PR にだけ当てる

## Context

platform の ADR 0021 は、PR の差分のレビューを通常と念入りに分け、念入りを「依頼者が念入りに頼んだ PR」と「全体の
レビューの報告から作る PR」に当てた。念入りは、観点ごとに読む人を並べ、打ち切りを持たない。

全体のレビュー #283 の報告から作った依頼 #305（PR #319）は、この決まりで念入りに回った。PR 全体のレビューは数え直しを
挟んで 20 回、読む人は約 140 人分になり、時間とトークンを多く使った。毎回の読む人が 7 人で、打ち切りがないため、
細かな提案が出続けるかぎり終わらなかった。

依頼者は、念入りにするのは明示の指定と全体のレビューそのもののときだけでよく、全体のレビューから生じた Issue に
対処するときは、指定がなければ念入りである必要はないと考えた（#328）。

## Decision

- 念入りの回し方は、依頼者が念入りに頼んだ PR にだけ当てる。全体のレビューの報告から作る PR も、頼まれなければ通常で
  回す。
- 全体のレビューそのものは、回し方によらず、範囲ごとに観点ごとに分けて読む（変えない）。
- 念入りの中身（観点ごとに並べること、打ち切りがないこと、上限の回数）は変えない。

## Alternatives

- **報告から作る PR を念入りのまま、念入りに打ち切りや一人あたりの重さの目安を置く**：念入りを頼んだ PR の回し方まで
  変わる。報告から作る PR は、直す中身が報告で決まっていて、全体のレビューで観点ごとにすでに読まれている。通常の
  打ち切りで残った提案は、次の全体のレビューで拾える。
- **報告の判断が要る点ごとに、念入りにするかを報告に書く**：報告を書く人が回し方まで決めることになり、決め方が一つ
  増える。依頼者が頼めば念入りにできるので、それで足りる。

## Consequences

- 報告から作る PR のレビューは一人で読み、必須のない PR 全体のレビューが 2 回続けば打ち切れる。報告の指摘を
  直した PR で新しく入った問題を見落とすことがありうるが、あとの全体のレビューで拾う（通常の回し方と同じ前提）。
- 念入りにしたい報告からの PR は、依頼者が依頼のときに頼む。
