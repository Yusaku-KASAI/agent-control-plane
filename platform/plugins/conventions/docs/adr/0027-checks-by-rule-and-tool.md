# 0027. 検査にするものを三つの条件で選び、置き場所を確かめる決まりと使う道具で決め、置いた区切りが前提にしてよいものだけを知らせる

## Context

#212（目的の手順が振り分けとロールに並んでいるかを確かめる）を足す前に、依頼者と、どこまでを検査で守るかを
話した（Slack、#212 のコメント）。検査はコマンド（`check-docs`、`check-protection`、`prctl`）、試験、CI のジョブ、hook に
散らばっていて、何を検査にするかと、どこに置くかの決まりがなかった。

依頼者は、検査の仕組みそのものが、依存してはいけない区切りに依存する形になってほしくないと考えている（例：
conventions が platform に依存してよいか）。調べると、`check-docs`（conventions）は platform も target-template も
知らず、conventions の形式が定めた形だけを見ていた。一方、`check-protection`（platform の github プラグイン）は、
target-template の用意の手順（`guides/github.md`）の写しと名乗っていて、最上位の地図にない platform から
target-template への向きになっていた。また、conventions の用語集の「役割」は、意味を platform のエージェントの用語集に
任せていた。

## Decision

- 次の三つを満たす決まりを検査にし、ほかはレビューの観点に任せる。判断が要らない（状態だけから機械で決まる）。
  実際に破られる（レビューで繰り返し見つかるか、手戻りが大きい）。誤って落ちにくい（保つ手間が見逃しの手戻りより
  安い）。意味の食い違いは検査にせず、その手がかりまでにする。
- 検査の仕組みも、それを置く区切りが前提にしてよいものだけを知る。置き場所は、確かめる決まりと使う道具で決める。
  - 一つの区切りの中の形：その決まりを定義する区切り。ほかの区切りの名前やパスを知らず、形から見分ける
    （`check-docs` の地図とロールの形の検査が、この形）。
  - 外の道具の状態：その道具を扱う区切り。決まりは前提にしてよい区切りから読む（Issue の決まりを GitHub で確かめる
    #111 は、conventions でなく GitHub を扱う platform に置く）。
  - 区切りの間の一致：契約の試験として、両側を前提にしてよい区切り（ターゲットが target-template の共通のファイルと
    ずれていないか、#131 は、platform や conventions でなく target-template か control-plane に置く）。
  - 置いた区切りが前提にしてよくないものを確かめたくなったら、確かめる値を契約に置き、検査は契約に合わせる。
- 決まりは文書の体系の「検査にするものと置き場所」に置く。
- 今の逆向きを直す。`check-protection` は、ターゲットの契約の「既定のブランチの守り」に合わせると名乗り、契約に
  なかった二つ（消せず force push できないこと、`check` の元を GitHub Actions に限ること）を契約に足す
  （target-template の ADR 0017）。conventions の用語集の「役割」を conventions 自身で定義し、エージェントの用語集の
  「ロール」はそれを指す。

## Alternatives

- **検査をすべて一か所（例：conventions のコマンド）に集める**：見つけやすいが、GitHub やターゲットの環境のような、
  conventions が前提にしてはいけないものを conventions が知ることになる。
- **区切りをまたぐ検査は control-plane のリポジトリだけに置く**：control-plane はすべての区切りを持つので向きは
  守れるが、ほかのターゲットや、ほかのリポジトリで使うときに検査が届かない。区切りの中の形と外の道具の状態は、
  その区切りのプラグインで配る。
- **何を検査にするかの条件を決めず、気づいたものから足す**：誤って落ちる検査や、意味まで確かめようとする検査が
  増え、ほかのターゲットに持ち込んだときに作業を止める。

## Consequences

- #212 の検査は conventions の `check-docs` に置くが、roles プラグインの特定のファイルは見ず、共通のルールの振り分けと、
  形式の「役割ごとの指示」で見分けたロールを見る汎用の検査にする。
- 検査を足すときは、この決まりで置き場所を決め、置いた区切りの文書（conventions なら形式の各節の「検査」）に書く。
