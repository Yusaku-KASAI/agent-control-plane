# 0055. 作業領域を書けない役割は、作業領域の主の作業ツリーとブランチだけを変えず、自分だけが使う所では自由に試す

## Context

ADR 0048 は、作業領域を書ける範囲に持たない役割（reviewer、pm、guide）が試すときの決まりを文書の体系の「手順と役割」に
置いた。主の作業ツリー（ファイル、index、HEAD）、作業領域のブランチ、ほかの worktree の HEAD を変えず、読むために
取り出すときに変わってよいのは worktree の登録とブランチでない refs だけ、とした。そのレビューは、この境目にまだ穴と
書き写しがあると挙げた（Issue #307）。変わってよい refs の範囲が広すぎること、自分の worktree に残った編集の扱いがないこと、
watch-tree がほかのローカルブランチの移動を知らせないこと、レビューするの手順とロールが短い版を書き写していることなど。

依頼者は、手元は自由に触ってよく、リモートに書ける所は付与する権限で限るのだから、それで隔離できているのではと問うた。
リモートに何を書けるかは役割の書ける範囲（GitHub App の権限）が決める。手元の決まりが要るのは、そこでの変化がほかの
役割を通してリモートに届くか、作業領域の片付けを止めるときだけである。

- サブエージェントとして動く役割は、頼んだ側と同じ作業領域にいる。そこに残したファイルは、書ける役割の `git add -A` で
  コミットに入り、その役割の権限で push される（platform の ADR 0016 の出来事）。ブランチを動かすと、そこにしかないコミットが
  失われる。
- 作業ツリーの変更は、作業領域の片付けを止める（ハーネスの契約の `changes`）。サブエージェントなどの worktree の
  ものは、worktree ごと消せばよい。

## Decision

- 作業領域を書ける範囲に持たない役割が変えないものは、作業領域の主の作業ツリー（そのファイル、index、HEAD）と、
  作業領域のブランチだけにする。理由（コミットに紛れる、コミットを失わせる、片付けを止める）を決まりのそばに一文で
  置く。変わってよい refs の列挙（worktree の登録、ブランチでない refs）はやめる。読むための fetch や worktree の追加は
  変えないものに当たらない。
- 試すための編集や検査は、自分だけが使う所（隔離して動くときの自分の worktree か、作業領域の外の一時的な場所）でし、
  その中は自由に変えてよい。自分の worktree に残ったものは、戻さずに worktree ごと消してよい。GitHub に書くための
  作業用のファイルは、これまでどおり作業領域の外の一時的な場所に置く。
- レビューするの手順とロールは、この決まりを書き写さず「手順と役割」を案内する。
- 書ける範囲から出てくる締めの扱い（作業領域にしかないもののうち自分の worktree のほかは捨てず、中身を Issue に
  残し、捨てることを人が解くものとする）は、セッションを締める手順の 6 段に置き、reviewer と pm のロールは手順を
  案内するだけにする。

## Alternatives

- **読むときに変わってよい refs を、origin から fetch する remote-tracking、`refs/prctl/`、自分が足した worktree の
  登録に限る**（#307 の初めの案）：穴は塞がるが、守る理由のないものまで列挙し続けることになる。境目を守るものの側
  （主の作業ツリーとブランチ）で引けば、列挙は要らない。
- **自分の worktree で試した編集を終える前に戻させる**：戻し忘れが残り、戻すための手間も増える。worktree ごと消せば
  失われるものはない。
- **試すことを作業領域の外に限る**：隔離の worktree（作業領域の中の `.claude/worktrees/`）が使えなくなり、PR の head で
  検査を回す手間が増える。
- **watch-tree がほかのローカルブランチの位置も比べて知らせる**：ブランチを変えない決まりと隔離で足り、ほかの
  ブランチを動かされたことはまだ起きていない。起きたら別に決める。
- **手元の決まりをやめ、権限だけで隔離する**：サブエージェントは頼んだ側の作業領域と認証情報を使うので、手元の
  変化がそのまま書ける役割のコミットと push に届く。

## Consequences

- 「手順と役割」の決まりが短くなり、レビューするの手順、reviewer、roles の全体像はそこを案内するだけになる。
- 片付けを止めるのは、主の作業ツリーの変更と、作業領域の中の worktree に残ったもの。後者は締めの 6 段で worktree ごと
  消せる。
- ほかのローカルブランチを動かしても、watch-tree は知らせない（ADR 0016 の比べるものは今のブランチの名前まで）。
