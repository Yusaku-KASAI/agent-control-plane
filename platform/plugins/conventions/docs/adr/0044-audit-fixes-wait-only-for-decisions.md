# 0044. 全体のレビューの報告からの直しは、判断が要る点にかかるものだけ答えを待つ

## Context

ADR 0013 は、全体のレビューの直しを「報告への答えを受けてから」行うとした。その後、レビューの扱い方の「全体のレビュー」は
「判断が要る点にかかる直しは、その答えを受けたものだけにする」に変わった（d6bf03d。全体のレビューの順序を条件の形に
書き直したとき）。必須と提案のうち判断の要らないものは、答えを待たずに直してよいという意味になったが、それを記録した
ADR はなかった。

全体のレビュー #283 の判断 15 で、依頼者は、意味を変えたものとして改める ADR を足すと決めた（#284）。

## Decision

- 全体のレビューの報告からの直しのうち、判断が要る点（決まりを変えるもの、どちらにも理由がある選択、答えによって直し方が
  変わる質問）にかかるものは、その答えを受けてから直す。ほかの必須と提案は、答えを待たずに直してよい。
- ADR 0013 のほかの決定（レビューを独立して定義し、差分と全体で観点と指摘の形をそろえる）は変えない。

## Alternatives

- **レビューの扱い方を ADR 0013 の文言（すべて答えを受けてから）に戻す**：判断の要らない必須（決まりに反する、文書が
  実装と違う）まで待たせることになる。報告は直す人がその Issue とリポジトリだけで直せるように書くので、判断の要らない
  直しを待たせる理由がない。

## Consequences

- ADR 0017 は、レビューの手順の置き場所を変えた点で ADR 0013 を改めていたが、`amends` に挙げていなかった。この ADR と
  合わせて、0017 の `amends` に 13 を足し、0013 から両方をたどれるようにする。
