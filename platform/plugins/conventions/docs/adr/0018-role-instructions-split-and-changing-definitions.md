# 0018. 役割ごとの指示を「固有の振る舞い」と「使う決まり」の節に分け、決まりを変える変更には載せた届け方を探して直すパターンを当てる

## Context

ADR 0009 で、役割ごとの指示は、役割に固有の振る舞いを自分で持ち、ほかの決まりは出典を示して届けるとした。ところが
一つの文書に両方が混ざり、どの行がその役割だけの定義で、どの行が定義を変えたら直すものかが分からなかった。#104 で
reviewer と developer から外した「正しさは design スキル、設計は principles スキル」の行は、出典のない要約だった。

決まりを変えたときに、それを載せた届け方を直すことは、定義と届け方には書いてあったが、変更の種類から当てはめる
パターンを引く表（変更とパターン）にはなかった。

## Decision

- 起点が自分で持つものと、ほかの定義の要約と案内が一つの文書に混ざるときは、節で分ける。役割ごとの指示は、「固有の
  振る舞い」（その役割だけの定義）と「使う決まり」（ほかの定義の要約と案内）の節に分け、判断の軸になる「使う決まり」を
  先に置く。
- 変更とパターンの表に、「決まり（定義）を足す、変える、消す」には「一つの出典から届ける」を当て、それを載せた届け方と
  それを確かめる検査を探して直す、という行を足す。直すものの中身は定義と届け方への案内にし、表には書き写さない。
- 共通のルールで文書の体系を全体まで読ませる場面に、決まりや文書を「変える・消す」ときを足す。

## Alternatives

- **節で分けず、要約と案内の行にだけ出典を付ける**：出典の付け忘れと、その役割だけの定義との区別がつかない。
- **「使う決まり」の各行に出典があるかを検査する**：節で分けたので検査できるようになったが、ロールの出典はパスの書き方が
  まちまちで、まず形をそろえてからにする。

## Consequences

- 「使う決まり」の節の各行に出典か案内があるかは、検査していない。
- guide ロールは、固有の振る舞いだけを持つので、節に分けない。
