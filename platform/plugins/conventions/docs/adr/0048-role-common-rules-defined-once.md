# 0048. ロールに共通の但し書きは conventions で一度だけ定義し、ロールの指示から外す

## Context

全体のレビュー #283 の D は、ロールの指示について次を挙げた。

- reviewer の「固有の振る舞い」が、レビューする手順とレビューの扱い方の書き写しになっている（必須）。
- 四つのロールに同じ但し書き（聞いて待てないとき、Slack への投稿はハーネスの契約による）があり、三つのロールに
  「試すときは自分の worktree か `mktemp -d`」がある。developer と reviewer は行数の上限ちょうどで、行を伸ばして収めている。
- pm の要約が出典（整っている状態）の「依頼者かエージェントが」の限定を落としている。ロールがハーネスの契約をパスなしで
  指している。

#297 で、聞いて待てないときの決まりを文書の体系の「手順と役割」に定義し、共通のルールに載せ、迷うなら取り消せる方、
公開や権限を広げない方を選ぶことを足した。書ける範囲の外の書き先がハーネスの契約によることは、形式の役割ごとの指示に
置いた。

## Decision

- ロールに共通の但し書きは、conventions で一度だけ定義し、ロールの指示から外す。
  - 聞いて待てないとき：#297 が、どの手順にも当たる手順の決まりとして文書の体系の「手順と役割」に置き、共通のルールに
    要約を載せた。この ADR はロールから外すだけにする。迷うときの向き（取り消せる方、公開や権限を広げない方）は、[拒否を
    既定にする](../../../principles/docs/reference/principles.md#fail-safe-defaults)考え方による。
  - 次の二つは、どの役割にも当たり、役割の書ける範囲から出てくる決まりとして、文書の体系の「手順と役割」に横断の決まりと
    して置く（ADR 0039 が文書の体系に置くとした横断の決まりに、役割に共通の決まりを足す）。この条件に当たるものだけを
    ここに置く。
    - 書ける範囲の外の書き先（チャットへの投稿など）：文書の体系の「手順と役割」に、役割の書ける範囲は作業領域と
      GitHub についてのもので、ほかの書き先はハーネスの契約による、と置く。形式の役割ごとの指示はそこを指す。
    - 試すときの場所：作業領域を書ける範囲に持たない役割は、作業領域の主の作業ツリー（そのファイル、index、HEAD）を
      変えず、試すための編集や検査と作業用のファイルは、隔離して動くときの自分の worktree か作業領域の外の一時的な場所に
      置く、と置く。境目を「作業領域の中か外か」ではなく「主の作業ツリーを変えないか」にするのは、隔離の worktree が
      作業領域の中（`.claude/worktrees/`）にあり、読むために取り出す作業ツリーも作業領域の refs と worktree の登録を
      増やすから。書ける範囲のない役割も、ここで試してよい。隔離の仕組みは roles の全体像が持ち、roles の全体像
      から書き先の扱いを手順と役割へ案内する。
- ロールの指示の節の中身（reviewer の固有の振る舞いを固有の定義だけにすること、developer のレビューの節を案内に
  下げること）は、定義と届け方（固有の振る舞いはその役割だけの定義、ほかは要約と案内）を当てはめた直しで、この ADR では
  決めない。

## Alternatives

- **共通の但し書きを共通のルールにだけ書く**：共通のルールは要約と案内で、定義は conventions の `docs/` に置く決まり
  （定義と届け方）に反する。
- **試すときの場所を roles の全体像にだけ置く**：roles の全体像は、そこを指すロールの指示からしか読まれず、roles
  プラグインの外の `.claude/agents/` のロールや、全体像を指さないロールに届かない。文書の体系はどの作業でも始めに
  読まれる。
- **参照の文書（届け方の決まりなど）に定義し、手順と役割から案内する**：参照の文書は作業の始めに読まれないので、
  案内を一段たどらないと届かない。文書の体系は、共通のルールがどの作業でも始めに全体まで読ませる。
- **ロールの指示に但し書きを残し、出典だけを付ける**：同じ一文が四つのロールに残り、定義を変えたときに直す所が増える。

## Consequences

- ロールの指示は、受け持つ手順、使う決まりの要約、固有の振る舞いだけになり、行数と行の長さに余裕ができる。
- 役割の振る舞いに共通の決まりを足すときは、上の条件に当たるものだけを文書の体系の「手順と役割」に置き、ロールの
  指示には書かない。役割ごとの指示の形（節と並べ方）は、形式の役割ごとの指示に置く。
