# 0007. 在りかを示すだけのリンクは、消さずにタイトル「案内」を付けて、依存の向きの確かめから外す

## Context

ADR 0006 で、前提にされる側から前提にする側の在りかを示すときは、リンクにせず文章で書くことにした。書いてみると、
インラインコードでパスを書くことになり、クリックできず、パスが実在するかも確かめられなかった。また、参照を消せば
依存の向きの確かめを避けられるので、本当の依存も同じ書き方で隠せた。

## Decision

- 在りかを示すだけで前提にしないリンクには、Markdown のリンクのタイトル `"案内"` を付ける。
- 案内のリンクは、実在するかを確かめ、依存の向きの確かめからは外す。索引からのリンクと ADR へのリンクは、タイトルが
  なくても案内として扱う。

## Alternatives

- **リンクにせず文章やインラインコードで書く（ADR 0006 のまま）**：クリックできず、パスの誤りに気づけず、依存を隠せる。
- **案内のリンクを決まった節（「関連」など）に集める**：文の中で自然に示したい在りかを、節に分けて書くことになる。
- **リンクのテキストに印を付ける（「→」など）**：表示に印が出て読みにくく、テキストの書き方と意味が混ざる。

## Consequences

- 案内かどうかは書き手が決めるので、レビューで、タイトル「案内」のリンクが本当に在りかを示すだけかを見る。
