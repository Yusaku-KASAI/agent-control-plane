# 0016. 文書の届け方が定義を載せる形を「写し」と呼ばずに要約と案内で表し、いつも読み込む要約を「共通のルール」と呼ぶ

## Context

ADR 0009 で、届け方が持つ定義の要約や選び出しを「写し」と呼んだ。ADR 0015 で、ほかの文書の中身への触れ方を要約と
案内に分けた。「写し」は原文どおりに写したものと読めるうえ、中身を言い直す要約と、どれを使うかを選ぶ判断という
別々のものを一語にまとめていた。

また、`rules/` の文書を、用語集は「いつも読み込む要約」、CLAUDE.md と文書の見出しは「共通のルール」と呼んでいた。
一つのものに二つの名前があり、要約と案内を持つ文書を「要約」と呼ぶことにもなっていた。

## Decision

- 「写し」という言葉をやめる。文書の届け方（共通のルール、役割ごとの指示、スキル）は、定義を要約か案内で載せる、
  と書く。どれを載せ、どちらの形にするかは判断
  （選び出し）として扱い、用語にしない。
- `rules/` の文書を「共通のルール」と呼び、「いつも読み込む要約」という名前をやめる。
- principles のパターン「一つの出典から届ける」は、出典から作る形を「出力」と呼び、出力は出典の要約か案内だけを書く、
  と書く。
- 共通のルールとロールの前置きでは、括弧の中のリンクの先にあるものを「決まり」ではなく「定義」と呼ぶ。

## Alternatives

- **「写し」を残し、要約と選び出しの総称として定め直す**：言葉から原文どおりと読める弱さが残り、要約と案内の書き分けと
  二重になる。
- **「要約」を総称にする**：案内は要約ではなく、「いつも読み込む要約」とも衝突する。

## Consequences

- ADR の本文の「写し」「いつも読み込む要約」は、書いた時点の記録として書き換えない。今の姿は文書の体系と用語集にある。
