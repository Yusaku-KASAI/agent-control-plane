# 0012. すべての文書を、人の入口（README.md）とエージェントの入口（CLAUDE.md）の両方からリンクでたどれるようにする

## Context

文書の根ごとに、索引がその根の文書を載せているかは検査していた。根どうしのつながりは検査していなかった。
README.md と CLAUDE.md からリンクだけをたどると、116 の文書のうち 14 に行き着けなかった。

- principles と conventions の索引は、hook が絶対パスで示すだけで、どの文書からもリンクされていなかった。
- その中の ADR も、たどれなかった。
- ルール、スキル、役割ごとの指示は、Claude Code の仕組みで読み込まれるので、リンクがなくても使われていた。

人も、仕組みを通さずに読むエージェントも、これらに行き着く道がなかった。

## Decision

- リポジトリのすべての Markdown を、ルートの `README.md` と `CLAUDE.md` のそれぞれからリンクでたどれるようにする。
  案内のリンクもたどる。ディレクトリへのリンクは、その中の文書すべてに行き着くとみなす。
- ルール、スキル、役割ごとの指示も例外にせず、プラグインの overview の構成要素から案内のリンクでつなぐ。
- `check-docs` で確かめる（文書の形式の「入口からの道」）。

## Alternatives

- **索引ごとの検査だけにする**：根どうしがつながっているかは見えず、根ごと孤立しても気づけない。
- **仕組みで読み込まれるものを除く**：エージェントには届くが、人は読む道を知らないままになる。どの仕組みで
  読み込まれるかの一覧を検査が持つことにもなる。
- **入口を一つにする**：人とエージェントで読み始める場所が違うので、片方からしかたどれない文書が出る。

## Consequences

- 文書を足すときは、どこからリンクするかも決める。
- 各ターゲットも、共通の `check-docs` を取り込むとこの検査を受ける。
