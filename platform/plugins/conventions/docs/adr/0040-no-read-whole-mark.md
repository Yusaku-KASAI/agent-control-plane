# 0040. 「（全体を読む）」の印をやめ、スキルには届ける手順を全体まで読んで沿うと直に書く

## Context

ADR 0015 で、リンクの直後の「（全体を読む）」で、その場面で全体まで読ませる文書を示すことにし、ADR 0017 で、スキルの
手順への案内にそれを付けることにした。ADR 0020 で、場面を限った「（全体を読む）」は読まれにくく、直に書かれた在りかは
読まれることが分かり、目的の手順の「始めに読む」の段と、起点に直に並べる形に移した。

全体のレビュー #283 の時点で、「（全体を読む）」を使っていたのは6 つのスキルの 7 本のリンクだけだった。それなのに、印の決まりが
共通のルールの 4 行、文書の体系の一節、用語集の一項目を占めていた。依頼者は、判断 5 をおすすめの (a) で進めると決めた（#284）。

## Decision

- 「（全体を読む）」の印と、読む範囲の決まりをやめる。
- スキルは、届ける手順を全体まで読んで沿う、と文で書く。
- 全体まで読ませる文書の示し方は、どの作業でも（共通のルールの「始めに読む」）、目的の手順に入ったとき（「始めに読む」の
  段と、起点に直に並べる）、スキルを使うとき（スキルの文）の三つにし、届け方の決まりの「起点」に置く。ほかのリンクは、要るときに
  リンク先の節を読む。

## Alternatives

- **スキルの形だけの決まりとして残す（判断 5 の (b)）**：印を使うのがスキルだけなら、印という仕組みを持つより、スキルに
  文で書く方が単純で、読み手が印の意味を知らなくても通じる。
- **残す（同じく (c)）**：共通のルールの行数と、毎回読む文書の量を、7 本のリンクのために使い続ける。

## Consequences

- 共通のルールから「読む範囲」の節がなくなり、行数に余裕ができる。
- スキルの文で全体まで読まれるかは、確かめていない。ADR 0020 の数え方で数え直すときに、スキルからの読みも数える。
