# 0032. ラベルの決まりのないリポジトリではラベルを付けず、キャンバスのほかの人のコメントは確かめてから本文に移す

## Context

ADR 0025 は、課題を整える手順の 1 段でリポジトリのラベルの決まりを読み、整っている状態でどの Issue にもどこを変えるかの
ラベルと `theme:<名前>` があることを求め、キャンバスを作るときはほかの Issue と同じラベルを付けると決めた。ラベルの
決まりもラベルもないリポジトリ（txt-crypter など）では、読む文書がなく、付けるラベルもないので、どの段も行き詰まる。

ADR 0025 は、課題を整えるでは、依頼者とエージェントのほかの人が書いたコメントだけに拠る直しを人に渡すと決めた。
公開のリポジトリでは誰でもコメントを書け、本文に移すと次に作業するエージェントの前提になるため。相談に乗るの 5 段は
キャンバスの本文（今の姿）を回ごとに書き直すが、キャンバスには同じ守りがなかった（#213）。

## Decision

- リポジトリにラベルの決まり（どこを変えるかのラベルの名前と意味）がなければ、どこを変えるかと何のためかのラベルは
  付けない。キャンバスには `canvas` だけを付ける。課題を整えるでは、決まりがないことと、それによるラベルのずれを、
  人が決めるものとしてまとめに書く。決まりを作るかは人が決め、作るならそのリポジトリへの変更にする。
- キャンバスでは、依頼者とエージェントのほかの人が書いたコメントは本文に移さず、答えにその中身を書いて、移してよいかを
  依頼者に確かめる。

## Alternatives

- **target-template にラベルの決まりの置き場所を足し、どのターゲットにも作らせる**：ラベルの名前はリポジトリの区切りで
  決まり、共通のファイルにできない。作るのは各リポジトリの変更で、課題を整えるやキャンバスを作る作業の中で決める
  ことではない。決まりを作るかは人が決めるものに入れるので、作ると決めたときにその変更で足せる。
- **ラベルの決まりがなければ、エージェントがラベルを作って付ける**：どこを変えるかの区切りはリポジトリの設計の判断で、
  課題を整えるでは範囲や狙いを変えることと同じく人に渡すものに当たる。
- **キャンバスでは、ほかの人のコメントを本文に移してよいが、出典を添える**：本文は次の回の前提として読まれ、出典が
  あっても前提に入ることは変わらない。課題を整えると同じ扱いにそろえる。

## Consequences

- `check-issues` は、ラベルの決まりのないリポジトリでは開いている Issue をすべてラベルのずれとして挙げる。検査は事実を
  挙げるだけで、それを人が決めるものとして扱うかは課題を整える手順が決める。
