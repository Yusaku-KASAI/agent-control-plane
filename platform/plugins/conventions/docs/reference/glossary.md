# 用語集（文書と作業）

このプロジェクト群の文書の体系と作業の進め方で使う言葉。エージェントとハーネスの言葉は platform の用語集にある。

| 言葉 | 意味 |
| --- | --- |
| 区切り | 知識を、使う人（誰が読めるか）と持ち主で分けた単位。platform、target-template、control-plane、各ターゲット。Bounded Context に当たる |
| 契約 | 区切りの間で受け渡すものの約束。ハーネスの契約とターゲットの契約がある |
| 文書の種類 | 解説（今の姿と考え方）、手順（目的を果たす手順）、参照（引くための事実）、判断（ADR）の 4 つ |
| 入口 | 最初に読まれる文書。人には README、エージェントには CLAUDE.md |
| 索引 | リポジトリの文書の唯一の一覧（`docs/README.md`） |
| 原則 / パターン | 原則は何を大事にするか、パターンはそれを特定の問題への形にした解き方 |
| 構成要素の説明 | アーキテクチャの文書で、構成要素ごとに責務、置くもの / 置かないもの、関係、当てはめた原則・パターンを書いたもの |
