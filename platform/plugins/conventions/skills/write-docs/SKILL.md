# 文書を書く

文書を足したり書き換えたりするときの手順。分け方の全体は[文書の体系](../../docs/architecture/documentation.md)にある。

1. **区切りを決める**：誰が読む必要があるか。読む必要がある人すべてに届く区切りに置く。どの区切りにも要るなら
   共有の核に置き、特定の区切りの間で要るなら契約にする。
2. **種類を決める**：解説、手順、参照、判断のどれか。混ざるなら分ける。
3. **持ち主を探す**：その事実を持つ文書がすでにあるか。あればそこを書き換え、ほかからはリンクする。なければ、
   区切りと種類に合う文書に書くか、新しく作って `docs/README.md` に足す。
4. **形に合わせる**：アーキテクチャの文書の構成要素と ADR は[形式](../../docs/reference/formats.md)に沿う。言葉は用語集に従う。
5. **リンクを分ける**：在りかを示すだけのリンクには、タイトル「案内」を付ける。リンク先を読まなくても、リンクを含む文が
   それだけで分かり正しいなら案内、そうでなければ前提（[形式](../../docs/reference/formats.md#links)）。全体（`overview.md`、
   索引）から子へのリンクは案内にする。前提のリンクは、地図の前提の向きに沿わせる。
6. **地図を直す**：項目を足す、移す、消すとき、または項目が前提にするものが変わるときは、その親の地図（親の
   `overview.md`）を直す（[形式](../../docs/reference/formats.md#map)）。
7. **確かめる**：`make check-docs` を通す。
