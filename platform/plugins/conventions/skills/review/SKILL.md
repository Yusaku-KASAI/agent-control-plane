# レビュー

レビューするときと、レビューの指摘に答えるときは、[レビューする](../../docs/guides/review.md "在りか")（全体を読む）の手順に
沿う。全体のレビューでは、[レビューの扱い方](../../docs/reference/reviews.md "在りか")（全体を読む）も読む。

- 自分が変更した差分は、自分では見ずにサブエージェントに渡す。渡すのは、依頼の内容、変更の意図、差分の三つだけ
  （[差分のレビュー](../../docs/reference/reviews.md#diff)）。
- 選んだ観点を結果に書く（[観点](../../docs/reference/reviews.md#perspectives)）。
- PR のレビューの残し方と、指摘への答え方は github スキルにある（ほかの人の PR は「ほかの人の PR と既定のブランチを
  読む」）。
