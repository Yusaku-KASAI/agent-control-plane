# セッションを締める

セッションを締めるよう頼まれたら、目的の手順の[セッションを締める](../../docs/guides/close-session.md "在りか")を全体まで
読み、沿う。その 1 段で、課題の扱い方を全体まで読む。

要約すると：

- 作業領域を残す理由を、ハーネスの契約にある確かめ方で確かめ、続く作業、作業領域にしかないもの、人が解くものに
  分ける（[残す理由の扱い](../../docs/reference/issues.md#leftovers)）。続く作業（このセッションのブランチを head か base とする
  開いている PR）があれば、締めずに、マージするか閉じてから頼み直すよう人に返す（[セッションを締める](../../docs/guides/close-session.md)の 2 段）。
- 覚えていることだけでなく、スレッド、PR の本文とレビュー、作業領域を読み直して、持ち越すものを挙げる（同じく 3 段）。
- 持ち越すものは Issue にだけ残し、引き継ぎのための文書やファイルは作らない
  （[持ち越すもの](../../docs/reference/issues.md#carry-over)）。すでにある Issue に書き足すときは、済んでいないものを
  閉じた Issue やコメントに埋もれさせず、切り出すか、範囲の中の項目にするか（閉じていれば開き直すこともある）を、
  [済んでいないものの置き場所](../../docs/reference/issues.md#append)で決める。
- この手順では文書やコードを直さず Issue にする（同じく 4 段）。
- 作業領域にしかないものは、中身を Issue に書いてから捨てる。人が解くもの（どこにも入っていないリモートのブランチ
  など）は消さず、中身を Issue に書いて、残る理由として締めのまとめに書く。理由に当たらないものは扱わない（同じく
  6 段、[残す理由の扱い](../../docs/reference/issues.md#leftovers)）。
