# セッションを締める

セッションを締めるよう頼まれたら、目的の手順の[セッションを締める](../../docs/guides/close-session.md "在りか")（全体を読む）に
沿う。その 1 段で、課題の扱い方を全体まで読む。

要約すると：

- 片付けを止めているもの（残す理由）を、動き方ごとにハーネスの契約にある確かめ方で確かめ、続く作業、作業領域に
  しかないもの、人が解くものに分ける。続く作業（このセッションのブランチを head か base とする開いている PR）が
  あれば、締めずに、マージするか閉じてから頼み直すよう人に返す（[セッションを締める](../../docs/guides/close-session.md)の 2 段）。
- 覚えていることだけでなく、スレッド、PR の本文とレビュー、作業領域を読み直して、持ち越すものを挙げる（同じく 3 段）。
- 持ち越すものは Issue にだけ残し、引き継ぎのための文書やファイルは作らない
  （[持ち越すもの](../../docs/reference/issues.md#carry-over)）。
- この手順では文書やコードを直さず Issue にする（同じく 4 段）。
- 作業領域にしかないものは、中身を Issue に書いてから捨てる。人が解くもの（どこにも入っていないリモートのブランチ
  など）は消さず、中身を Issue に書いて、残る理由として締めのまとめに書く。理由に当たらないものは扱わない（同じく
  6 段）。
