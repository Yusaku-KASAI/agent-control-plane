# セッションを締める

セッションを締めるよう頼まれたら、目的の手順の[セッションを締める](../../docs/guides/close-session.md "在りか")（全体を読む）に
沿う。その 1 段で、課題の扱い方を全体まで読む。

要約すると：

- 覚えていることだけでなく、スレッド、PR の本文とレビュー、作業領域を読み直して、持ち越すものを挙げる
  （[セッションを締める](../../docs/guides/close-session.md)の 2 段）。
- 持ち越すものは、種類ごとに決まった置き場所（Issue か PR）に残し、引き継ぎのための文書やファイルは作らない
  （[持ち越すもの](../../docs/reference/issues.md#carry-over)）。
- この手順では文書やコードを直さず Issue にする。作業領域にしかないものを PR に載せるなら変更を届けるに入り直し、
  載せないなら中身を Issue に書いてから捨てる（同じく 3 段、5 段）。
