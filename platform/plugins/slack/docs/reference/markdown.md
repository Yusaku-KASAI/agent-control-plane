# Slack の markdown ブロックが読む形

標準の Markdown を Slack の markdown ブロック（`slackctl post` と control-plane が投稿に使う）で送ったとき、Slack が
どう読むか。Slack は受け取った Markdown を rich_text、table、header、divider のブロックに直して保存し、
それを表示する。保存されたブロックは Web API（`conversations.replies` など）の `blocks` で読める。表の中身は、試しに
投稿し、保存されたブロックを読んで確かめたもの（2026-10-25）。

<a id="forms"></a>

## 形ごとの読み方

| 形 | Slack の読み方 | 崩れない書き方 |
| --- | --- | --- |
| 太字（`**…**`）、斜体（`*…*`）、打ち消し（`~~…~~`） | 前後に空白がなくても効く（`前**太字**後`）。ただし、記号として扱うのは ASCII の記号だけで、全角の記号（`、`、`：`、`（`）は文字として扱う。そのため、`**` の内側が ASCII の記号（`` ` ``、`#`、`(`、`"`、`.`、`<https://…>` の `<` など）で、外側が空白でも ASCII の記号でもないと、`**` がそのまま出る（`、**#21 …**：`、``**`code`**：``、`前**(注)**後`） | 内側が ASCII の記号で始まるか終わるときは、`**` の外側に空白を置く（``**`code`** ：``）か、記号を外に出す |
| 斜体（`_…_`） | 前後に空白がないと効かない | `*…*` を使う |
| インラインコード | 前後に空白がなくても効く。中の `<`、`>`、`&` はそのまま出る | — |
| 裸の URL | 前が空白か ASCII の記号か行頭のときだけリンクになる。リンクは次の空白までの文字を含む（`https://example.com/a、後` は `、後` までがリンクになる）。末尾の `.` や `)` は含まない | `<https://…>` か `[表示](https://…)` で書く |
| 表 | GitHub の表の書き方（先頭と末尾の縦線は省ける）で `table` ブロックになり、セルの中のコード、太字、リンクも効く。直前の行が空行でないと表にならず、行がそのまま出るか、直前のリストの項目に入る。セルの中の縦線は、コードの中でも区切りになる | 表の前に空行を置く。セルの中の縦線は、下の注のとおりに書く |
| 見出し（`#`） | `header` ブロックになり、中の書式（太字、コード、リンク）は消えて文字だけになる | 見出しに書式を入れない |
| リスト | 入れ子と番号付きのリストは効く。ただし、番号付きのリストの項目の下に入れ子（箇条書きでも番号付きでも）を置くと、Slack はリストを入れ子の前後で分け、後ろの項目の番号を 1 から振り直す（`1. 一`、子、`2. 二` が 1、子、1 と出る）。番号付きのリストを段落で区切ると、後ろのリストは書いた番号から続く。項目の中の続きの段落（空行のあとの字下げした行）は、改行が消えて前の文に続く | 番号付きのリストの項目の下に入れ子を置かない。入れ子が要るときは、外側を箇条書きにするか、番号を太字の段落（`**1. 題**`）にしてその下にリストを置く。項目の中で段落を分けない |
| コードブロック | `rich_text_preformatted` になる。リストの項目の中に置くと、コードブロックにならず、中身が項目の文字に混ざる | コードブロックはリストの外に置く |
| 引用（`>`） | 効く。空行まで続く行は引用に入る | 引用の後に空行を置く |
| 区切り線（`---`） | `divider` ブロックになる | — |
| `<`、`>`、`&` | そのまま出る。実体参照（`&lt;` など）は、コードの外では元の文字になり、コードの中では `&lt;` のまま出る | 実体参照にせず、元の文字で書く |

- 表のセルの中の縦線は、バックスラッシュを前に付けて書く（GitHub の表の書き方と同じ）。Slack はそれを縦線として出す。

<a id="reading"></a>

## 読むときの形

Web API が返すメッセージの `text` は、`&`、`<`、`>` を `&amp;`、`&lt;`、`&gt;` に置き換えている。`<@U…>`（ユーザー）、
`<#C…>`（チャンネル）、`<https://…|表示>`（リンク）は、Slack の記法で、置き換えられた文字とは別のもの。Slack の画面には
置き換える前の文字で出るので、読んだ `text` を投稿に写すときは元の文字に戻す。`slackctl` は、戻した文字で出す。
