# check-markdown の出力

slack プラグインの `scripts/check-markdown` が出すものと、例の一覧（`tests/markdown-cases.json`）。`slackctl`、ターンの終わりの
hook のほか、Slack に投稿する前に Markdown を読むほかの道具も、これに合わせて使ってよい。変えるときは、使う側も直す。
何を見つけるかは[全体像](../overview.md "在りか")にある。

## 出力

- 標準入力の Markdown を読み、見つけた形を一つずつ `line N: <文>` の行で標準出力に出す。`N` は 1 から数える行の番号。
- 終了コードは、見つけたら 3、なければ 0。ほかの終了コード（捕まえていない例外の 1 など）は検知の失敗。

<a id="starts"></a>

## 文の書き出し

`<文>` は、形ごとに次の書き出しで始まる。使う側は、書き出しで形を見分けてよい。

| 書き出し | 形 |
| --- | --- |
| `URL を` | 裸の URL |
| `太字の内側が` | 太字の内側の端の ASCII の記号 |
| `表の前に` | すぐ上が文字の行の表 |
| `番号付きのリスト` | 入れ子のあとに続く番号付きのリストの項目 |
| `見出しに` | 見出しの中の書式 |
| `コードブロックは` | リストの中のコードブロック |

## 例の一覧

`tests/markdown-cases.json` は、例ごとに名前（`name`）、文（`text`）、知らせる行の番号（`found`）を持つ。使う側は、例を名前で
名指ししてよい。
