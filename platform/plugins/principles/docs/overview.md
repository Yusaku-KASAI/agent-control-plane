# principles の全体像

## 構成

どこでも通用する設計の拠り所を、原則とパターンの二つの一覧で持つ。原則は何を大事にするか、パターンはそれを特定の
問題への形にしたもの。パターンは原則を拠り所にし、原則はパターンを知らない。エージェントは principles スキルから
引く。
