# bell の全体像

## 構成

```
bell/
  hooks/hooks.json   止まり方ごとに、scripts/ring を回数と間隔を付けて呼ぶ
  scripts/ring       端末にベルを書く
```

- 聞き逃さないよう、どの場面でも2回以上鳴らす。すぐに人の操作が要る場面（操作すれば再開できる、または直す必要が
  ある）は短い間隔で2回、ターンを終えて結果を見ればよい場面は3回にして、聞き分けられるようにする。
- hook だけで、ほかのプラグインに依存しない。

## 構成要素

### `hooks/hooks.json`

- **責務**：どの止まり方で、何回、どの間隔で鳴らすかを決める。
- **置くもの / 置かないもの**：

  | 止まり方 | hook | ベル |
  | --- | --- | --- |
  | ターンの終わり | `Stop` | 3回、0.8秒おき |
  | API のエラーでの終わり（利用上限、認証の失敗など） | `StopFailure` | 2回、0.4秒おき |
  | 権限の確認 | `PermissionRequest` | 2回、0.4秒おき |
  | 質問、プランの承認 | `PreToolUse`（`AskUserQuestion`、`ExitPlanMode`） | 2回、0.4秒おき |
  | 入力待ちが続く、MCP やエージェントからの入力の依頼 | `Notification`（`idle_prompt`、`elicitation_dialog`、`elicitation_url_dialog`、`agent_needs_input`） | 2回、0.4秒おき |

  人が Esc で止めたときは、人がその場にいるので鳴らさない（`Stop` も動かない）。プロセスが落ちたときは hook が
  動かない。
- **関係**：`scripts/ring` を呼ぶ。

### `scripts/ring`

- **責務**：端末に、指定した回数だけ、間隔を空けてベルを書く。
- **置くもの / 置かないもの**：hook は自分の端末を持たないので、祖先のプロセスのうち端末を持つもの（対話で動いている
  Claude Code）の端末に書く。書くのは裏で行い、hook は待たずに戻る。tmux の中でも外でも同じ。`-p` で動く
  エージェントには端末を持つ祖先がないので、鳴らない。
