# 0025. 手順を終えられるかは、その手順の終わりの状態で決める（guide は相談に乗るを受け持ち、締めは受け持たない）

## Context

ADR 0019 は、ロールが手順を受け持つかを、そのロールの書ける範囲でその手順を終えられるか（結果を残せるか）で決めた。
guide は GitHub に何も書かない。guide の指示では、セッションを締めるは受け持たず（1〜3 段に沿い、残すのは pm に回す）、
相談に乗るは受け持つ（キャンバスは回答に書いて pm に回す）。どちらも Issue に書く段を持つのに扱いが違い、その理由が
conventions の ADR 0025 にも書かれていなかった（#213）。

## Decision

- 手順を終えられるかは、その手順の終わりの状態を、書ける範囲で作れるかで決める。途中に書けない段があっても、その段が
  条件付きで、書けないときの扱いを手順が持ち、終わりの状態に要らなければ、受け持てる。
- 相談に乗るの終わりは、考えを答えることで（6 段）、キャンバスに残す 5 段は条件付きの段で、書けないときは残す中身を
  答えに書いて書けるロールに回すと手順が決めている。guide は相談に乗るを受け持つ。
- セッションを締めるの終わりは、持ち越すものが Issue に残っていることで、書けないと終わりの状態を作れない。guide は
  受け持たず、洗い出すまでの段に沿って回す。課題を整えるも、終わりは Issue が整っている状態に合うことなので、
  受け持たない。

## Alternatives

- **相談に乗るも締めと同じ形にそろえ、guide は受け持たない（1〜4 段と 6 段に沿い、pm に回す）**：相談の多くはキャンバスに
  残さずに答えで終わり、guide の責務（質問と相談に答える）そのものに当たる。受け持たないと書くと、答えることまで
  回す先に任せるように読める。
- **相談に乗るの 5 段を、書けるロールでだけ行う段に分ける**：段の中に、書けないときの扱いがすでにある。段を分けると、
  手順がロールで切れることになる（conventions の ADR 0021）。

## Consequences

- ほかのロールの受け持ちも同じ決め方で読める。pm は締めを受け持ち、作業領域に書けない 6 段は中身を Issue に残して
  人に渡す（終わりの状態は Issue に残すことで作れる）。
