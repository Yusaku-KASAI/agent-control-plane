# 0025. 手順を受け持てるかは、書けないときの扱いを持たない段を書ける範囲で行えるかで決める（guide は相談に乗るを受け持ち、締めは受け持たない）

## Context

ADR 0019 は、ロールが手順を受け持つかを、そのロールの書ける範囲でその手順を終えられるか（結果を残せるか）で決めた。
guide は GitHub に何も書かない。guide の指示では、セッションを締めるは受け持たず（1〜3 段に沿い、残すのは pm に回す）、
相談に乗るは受け持つ（キャンバスは回答に書いて pm に回す）。どちらも Issue に書く段を持つのに扱いが違い、その理由が
conventions の ADR 0025 にも書かれていなかった（#213）。

三つの手順（相談に乗る、セッションを締める、課題を整える）は、どれも答えること（まとめ）で終わると冒頭に書く。
終わり方だけを見ると、どれも書かずに終えられるように読め、違いが出ない。

## Decision

- 手順を終えられるかは、その手順の書く段のうち、書けないときの扱いを手順が持たない段（条件が付かず、いつも行う段）を、
  書ける範囲で行えるかで決める。書く段が条件付きで、書けないときの扱い（答えに書いて回す、人が解くものとしてまとめに
  書くなど）を手順が持つなら、書けなくても受け持てる。
- 相談に乗るの書く段は、キャンバスに残す 5 段だけで、条件付きの段で、書けないときは残す中身を答えに書いて書ける
  ロールに回すと手順が決めている。guide は相談に乗るを受け持つ。
- セッションを締めるの 4 段（持ち越すものを Issue に残す）と、課題を整えるの 5 段（ずれを直す）は、条件の付かない
  書く段なので、Issue に書けない guide は受け持たず、その手前の段に沿って回す。

## Alternatives

- **相談に乗るも締めと同じ形にそろえ、guide は受け持たない（1〜4 段と 6 段に沿い、pm に回す）**：相談の多くはキャンバスに
  残さずに答えで終わり、guide の責務（質問と相談に答える）そのものに当たる。受け持たないと書くと、答えることまで
  回す先に任せるように読める。
- **相談に乗るの 5 段を、書けるロールでだけ行う段に分ける**：段の中に、書けないときの扱いがすでにある。段を分けると、
  手順がロールで切れることになる（conventions の ADR 0021）。

## Consequences

- ほかのロールの受け持ちも同じ決め方で読める。pm は締めを受け持つ。条件の付かない 4 段は Issue に書け、作業領域に
  書く 6 段は自分で解けるものだけを解き、ほかは人が解くものとしてまとめに書くと手順が決めている。
