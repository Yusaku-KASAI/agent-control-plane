# 用語集

エージェントとハーネスの言葉。どの文書でも、この意味で使う。文書の体系と作業の言葉は
[conventions の用語集](../../plugins/conventions/docs/reference/glossary.md)にある。

| 言葉 | 意味 |
| --- | --- |
| control-plane | エージェントのコンテナを起動し、依頼を届け、認証情報を渡して更新するアプリケーション（agent-control-plane） |
| platform | ターゲットをまたいで使うエージェントの能力（ロール、ルール、スキル、hook）を、Claude Code のプラグインとして配るマーケットプレイス `acp-platform` |
| ターゲット | エージェントが作業する環境と、その定義を持つリポジトリ。devcontainer（イメージ）、`.claude/settings.json`、CLAUDE.md を持つ |
| target-template | ターゲットに共通のファイルと、ターゲットの契約を持つひな形 |
| ハーネス | エージェントを動かす仕組みの全体：ターゲットのイメージ、プラグイン、それを起動する control-plane か devcontainer。どこで何が渡されるかは[ハーネスの契約](harness.md) |
| ロール | エージェントの役割（developer、guide など）。platform の roles プラグインがカスタムエージェントとして定義する |
| エージェント | ターゲットとロールの組。Slack では Bot 一つに当たる（例：control-plane-dev） |
| 依頼者 | エージェントに依頼を出した人 |
| セッション | 一つのエージェントとの一続きの会話と、その作業領域。Slack ではスレッドごとに一つ |
| 作業領域 | セッションごとに clone したターゲットのリポジトリ |
| セッションのブランチ | セッションが作業するブランチ `acp/<セッション ID の先頭8文字>` |
| ターン | 一つの依頼を受けてから、最後の回答を出すまで |
| head ブランチ / base ブランチ | PR のマージ元 / マージ先のブランチ |
| head コミット | head ブランチの先頭のコミット。あるコミットが「head コミットに入っている」とは、head コミットから履歴をたどってそのコミットに行き着くこと |
