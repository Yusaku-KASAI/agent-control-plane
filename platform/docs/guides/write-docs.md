# 文書を書く

文書を足したり書き換えたりするときの手順。分け方の全体は[文書の体系](../architecture/documentation.md)にある。

1. **区切りを決める**：誰が読む必要があるか。読む必要がある人すべてに届く区切りに置く。ほかの区切りの読み手にも
   要るなら、platform に置くか、契約にする。
2. **種類を決める**：解説、手順、参照、判断のどれか。混ざるなら分ける。
3. **持ち主を探す**：その事実を持つ文書がすでにあるか。あればそこを書き換え、ほかからはリンクする。なければ、
   区切りと種類に合う文書に書くか、新しく作って `docs/README.md` に足す。
4. **形に合わせる**：アーキテクチャの文書の構成要素と ADR は[形式](../reference/formats.md)に沿う。言葉は用語集に従う。
5. **確かめる**：`make check-docs` を通す。
