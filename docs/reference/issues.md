# Issue のラベル

このリポジトリの Issue に付ける、どこを変えるかのラベル。Issue の扱い方は conventions の
[作業の進め方](../../platform/plugins/conventions/docs/reference/workflow.md "案内")にある。

| ラベル | 変えるもの |
| --- | --- |
| `app` | control-plane のアプリの仕組み |
| `codebase` | control-plane のコードの構成と書き方、このリポジトリの devcontainer と検査 |
| `target` | target-template とターゲットの契約 |
| `platform` | platform のプラグイン、ハーネスの契約、エージェントの用語集、principles、conventions |
