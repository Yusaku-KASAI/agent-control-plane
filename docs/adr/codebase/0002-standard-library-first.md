# 0002. エラー、テスト、CLI は標準ライブラリで書く

## Context

エラー処理、テスト、コマンドライン解析にはそれぞれ定番の外部ライブラリがあるが、今の規模では
標準ライブラリで足りる。

## Decision

- エラーは `error` と `%w` によるラップで扱う。Result 型のような独自の仕組みは作らない。
- テストは `testing` で書き、アサーションライブラリやモック生成ツールは使わない。偽物は手書きする。
- CLI は `flag` で書く。

## Alternatives

- **testify などのアサーションライブラリ、mockgen などのモック生成**：インターフェースが小さいうちは
  手書きの偽物で十分で、依存と生成物が増える。
- **cobra などの CLI フレームワーク**：サブコマンドが少ないうちは不要。

## Consequences

- サブコマンドが増えて `flag` での分岐がつらくなったら、CLI フレームワークの採用を見直す。
