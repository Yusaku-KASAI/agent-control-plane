# 0003. 権限はコンテナの隔離と渡す認証情報で制御する

## Context

エージェントに何をさせてよいかを制御する方法には、Claude Code のツール許可設定（`allowedTools`、
settings.json）、実行途中で人間の承認を待つ仕組み、実行環境そのものの隔離がある。前の二つはエージェントと
同じ環境の中で効く設定であり、根本的な制御にはならない。承認待ちは自律的な作業を止める。

## Decision

- エージェントには、コンテナ内でできることはすべて許可する。安全性はコンテナの隔離で担保する。
- ロールごとの権限の違いは、コンテナに渡す認証情報・マウント・ネットワークの違いで表す。
- 認証情報を持っていれば、push や PR 作成などの外部への書き込みも承認なしで行ってよい。
  外部システム側の保護（ブランチ保護など）はその外部システムで行う。

## Alternatives

- **ツール許可設定でロールを制限する**：エージェントと同じ環境内の設定なので、境界として弱い。
- **外部への書き込みの前に Slack で人間の承認を待つ**：作業が止まり、実装も複雑になる。

## Consequences

- ロールを設計することは、そのロールに渡す認証情報とアクセス範囲を設計することになる。
- 渡した認証情報でできることは、すべて行われうる前提で権限を絞る。
