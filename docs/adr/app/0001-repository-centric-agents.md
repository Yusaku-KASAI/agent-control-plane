# 0001. エージェントの実行環境と役割はターゲットリポジトリが宣言する

## Context

エージェントの作業対象（プロダクトのコード、研究、雑務など）ごとに、必要な言語環境、ツール、規約、
役割は異なる。これを control-plane 側で持つと、リポジトリを見ても「エージェントがどう動くか」が分からず、
開発者向けの環境定義とも二重管理になる。

## Decision

ターゲットリポジトリが、自分の上で動くエージェントの実行環境（devcontainer）、役割ごとの指示、
必要な拡張、規約（CLAUDE.md）を宣言する。control-plane はそれを読んで実行するだけで、
汎用のエージェント像を押し付けない。コードを持たない作業にも、そのための作業用リポジトリを用意する。

## Alternatives

- **control-plane が汎用エージェントの環境と指示を持つ**：ターゲットごとの差異を control-plane が
  吸収することになり、依存が暗黙になる。

## Consequences

- ターゲットの devcontainer は、人間の開発環境とエージェントの実行環境を兼ねる。
- このリポジトリ自身もターゲットの一つとして宣言を持つ。
