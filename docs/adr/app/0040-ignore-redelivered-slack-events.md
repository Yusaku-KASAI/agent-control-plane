# 0040. Slack が送り直した同じメンションは、返事をせずに無視する

## Context

ADR 0016 は、Slack が同じイベントを再送すると同じセッションのターンが重なり、後の方は「処理中」と返す、とした。

実際の Bot は、同じメッセージ（チャンネルと ts が同じ）を 1 時間のあいだ一度だけ扱い、送り直されたものには何も
返さない（Issue #75）。また、セッションのプロセスは常駐し、ターンの実行中に届いた依頼は受信箱に積む（ADR 0017）。
「処理中」と返すのは、ターンが重なると断っていたころの扱いである。

## Decision

- Bot は、同じチャンネルと ts のメンションを、1 時間のあいだ一度だけ依頼にする。送り直されたものには、
  スレッドに何も書かない。
- 覚えておくのはプロセスのメモリの中だけにする。

## Alternatives

- **送り直されたものに「処理中」と返す**：依頼者が書いたのは一度だけなので、返事が増えるだけになる。受け付けた
  ことは、最初のメンションへのリアクションと状態メッセージで分かる。
- **送り直されたものも依頼にして、受信箱に積む**：同じ依頼が二度実行される。
- **扱ったメッセージを保存して、再起動をまたいで覚える**：Slack が送り直すのは受け取りの確認が届かなかったとき
  で、数秒から数分のうちに来る。再起動をまたぐ間に送り直されることは少なく、保存する仕組みに見合わない。

## Consequences

- 同じメンションが二度実行されない。
- 再起動の直前に受けたメンションが、再起動のあとに送り直されると、もう一度依頼になる。
- 1 時間を過ぎて送り直されたものは、新しい依頼として扱う。
