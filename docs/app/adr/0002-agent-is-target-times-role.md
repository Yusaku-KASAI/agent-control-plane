# 0002. エージェントは「ターゲット × ロール」で、Slack アプリ単位で識別する

- Status: Accepted
- Date: 2026-09-30

## Context

同じターゲットに対して、開発、進行管理など役割の違うエージェントを置きたい。利用者はどのチャンネルからでも
目的のエージェントを呼び出せる必要がある。

## Decision

- エージェントを「ターゲットリポジトリ × ロール」の組として定義する。
- Slack ではエージェントごとに Slack アプリ（Bot）を用意し、呼ばれた Bot からエージェントを特定する。
  チャンネルはエージェントの特定に使わない。

## Alternatives

- **1 つの Bot で、チャンネルやコマンド引数からエージェントを切り替える**：Slack アプリの管理は減るが、
  人間から見て今どのエージェントと話しているかが分かりにくい。

## Consequences

- エージェントを増やすたびに Slack アプリとそのトークンが増える。
- Bot とエージェントの対応は control-plane の 1 か所で管理する。
