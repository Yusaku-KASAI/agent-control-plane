# 0008. 手元の PC で動かすことから始め、実行基盤に依存しない作りにする

- Status: Accepted
- Date: 2026-09-30

## Context

最初の利用者は開発者本人で、手元の PC で動かせれば足りる。一方で、将来はサーバーやクラウドへ移す
可能性がある。

## Decision

- 最初は手元の PC の Docker で動かす。
- 特定のクラウドのサービスに依存せず、コンテナの実行、認証、保存先などを差し替え可能にしておく。

## Alternatives

- **最初からクラウドやオーケストレーターを前提にする**：最初の利用には過剰で、立ち上げが遅れる。

## Consequences

- 実行基盤に依存する部分は、差し替え可能な境界の内側に閉じ込める。
