# 0021. 依頼した人を、そのターンのコミットの共著者として記録する

- Status: Accepted
- Date: 2026-10-03

## Context

エージェントのコミットの作者はエージェントにしている（ADR 0012）。Slack からは複数の人が同じセッションに
依頼でき、誰の依頼でできた変更かを履歴に残したい。依頼者とコミットの対応を付けられるのは、依頼がどのターンに
取り込まれたかを知っている control-plane である（ADR 0019）。

## Decision

- ターンに取り込まれた依頼の依頼者を、そのターンのコミットの `Co-authored-by` にする。エージェントが自分で
  始めたターンでは、直前の依頼者を残す。
- Slack のユーザーと git の名前・メールアドレスの対応は control-plane の設定に書き、対応がない人は記録しない。
- 記録は、control-plane が作業領域に置く `commit-msg` フックが、control-plane の書き換えるファイルを読んで行う。

## Alternatives

- **セッションを始めた人だけを記録する**：途中で依頼した人が残らない。
- **スレッドに登場した全員を記録する**：議論に加わっただけの人まで共著者になる。
- **エージェントに依頼者を伝えて書かせる**：書き忘れが起きる。Claude Code の `attribution` 設定は起動時に
  決まり、ターンごとの依頼者を反映できない。

## Consequences

- フックはリポジトリにはコミットされず、`core.hooksPath` を設定しているターゲットでは働かない。
- PR の本文に依頼者を書くかどうかはエージェントに任されている。
