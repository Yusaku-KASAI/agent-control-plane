# 0005. 拡張は Claude Code の標準機能を優先し、コンテナの外に関わるものだけ独自に定義する

- Status: Accepted
- Date: 2026-09-30

## Context

エージェントの能力を拡張する手段として、Claude Code にはプラグイン、MCP サーバー、スキル、hook、設定がある。
一方、サイドカーコンテナの起動や認証情報の注入など、エージェントのコンテナの外で準備が必要なものは
これらでは表現できない。

## Decision

- コンテナの中で完結する拡張は、Claude Code の標準機能で定義する。
- コンテナの外の準備（サイドカー、認証情報の注入、ネットワークなど）が必要なものに限り、ターゲットが
  宣言できる独自の定義を設け、control-plane が解釈する。

## Alternatives

- **拡張をすべて独自形式で定義する**：Claude Code の標準機能やエコシステムと二重になる。
- **標準機能だけで済ませる**：サイドカーや認証情報の注入を表現できない。

## Consequences

- 独自の定義は、標準機能では足りない部分に限って増やす。
