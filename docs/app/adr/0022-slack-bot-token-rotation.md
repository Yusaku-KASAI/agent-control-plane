# 0022. Slack の Bot トークンはトークンローテーションで短命にし、control-plane が更新する

- Status: Accepted
- Date: 2026-10-03

## Context

エージェントには Slack の Bot トークンを渡している（ADR 0020）。長期のトークンは、漏れたときに取り消すまで
使われ続ける。Slack のトークンローテーションでは、アクセストークンが 12 時間で失効し、更新用のトークンで
更新する。更新用のトークンは使うと無効になり、更新のたびに新しいものが返る。長期のトークンは `oauth.v2.exchange`
でローテーションするトークンに交換できる。ローテーションは一度有効にすると無効にできない。

## Decision

- エージェントの Slack アプリの Bot トークンを、トークンローテーションで短命にできるようにする。
- 初回は設定された長期のトークンを交換し、以降は期限の 2 時間前に更新する。更新用のトークンは、
  control-plane だけが読み書きするボリュームに、使う前に保存する。
- 新しいトークンは、control-plane の Slack クライアントと、動いているエージェントの認証情報ファイルに反映する。
- Socket Mode の App-Level Token はエージェントに渡さないため、ローテーションの対象にしない。

## Alternatives

- **長期のトークンのまま使う**：エージェントの手元のトークンが漏れたときの影響が大きい。
- **エージェントには読み取り専用の別アプリのトークンを渡す**：エージェントが投稿できなくなる（ADR 0020）。

## Consequences

- control-plane が client secret を持つ。
- 有効にすると設定画面に Bot トークンは表示されず、交換した長期のトークンも使えなくなる。保存した状態を
  失ったときは、OAuth の認可で得たコードからトークンを取り直す（`acp slack-auth`）。
- 更新に失敗し続けると、12 時間後にエージェントと control-plane の Slack 操作が止まる。失敗はログに残る。
